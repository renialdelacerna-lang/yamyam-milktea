## File Descriptions

### Core Files

#### `lib/main.dart`
- **Purpose**: Application entry point
- **Key Functions**:
  - Initialize Hive database
  - Configure app theme
  - Set up routing
- **Important Code**:
  ```dart
  final databaseService = DatabaseService();
  await databaseService.initialize();
  runApp(YamyamApp(databaseService: databaseService));
  ```

---

### Models (`lib/models/`)

#### `product.dart`
- **Purpose**: Product/menu item data structure
- **Fields**:
  - `id`: Unique identifier (String)
  - `name`: Product name (String)
  - `category`: Product category (String)
  - `price`: Product price (double)
  - `description`: Product description (String)
  - `createdAt`: Creation timestamp (DateTime)
- **Key Methods**:
  - `copyWith()`: Create modified copy
- **Hive TypeId**: 0

#### `order.dart`
- **Purpose**: Order and order item data structures
- **Classes**:
  1. **OrderItem** (TypeId: 1):
     - `productId`: Reference to product
     - `productName`: Snapshot of product name
     - `productPrice`: Snapshot of product price
     - `quantity`: Number of items
     - Computed: `totalPrice`
  
  2. **Order** (TypeId: 2):
     - `id`: Unique identifier
     - `customerName`: Customer's name
     - `items`: List of OrderItem
     - `totalAmount`: Total order value
     - `timestamp`: Order creation time
     - `status`: Order status (Pending, Preparing, Completed, Cancelled)
- **Static Methods**:
  - `calculateTotal()`: Sum all item prices

#### `inventory.dart`
- **Purpose**: Inventory item data structure
- **Fields**:
  - `id`: Unique identifier
  - `ingredientName`: Ingredient name
  - `stockQuantity`: Current stock level
  - `unit`: Measurement unit
  - `lastUpdated`: Last update timestamp
  - `minStockLevel`: Low stock threshold (optional)
- **Computed Properties**:
  - `isLowStock`: Boolean indicating low stock
- **Hive TypeId**: 3

#### Generated Files (`.g.dart`)
- **Purpose**: Hive TypeAdapters for serialization
- **Generated by**: `build_runner`
- **When to regenerate**: After modifying model classes
- **Command**: `flutter pub run build_runner build --delete-conflicting-outputs`

### Services (`lib/services/`)

#### `database_service.dart`
- **Purpose**: Central database management
- **Responsibilities**:
  - Initialize Hive
  - Open/close boxes
  - Provide CRUD operations
  - Manage data persistence

**Box Management**:
```dart
Box<Product> _productBox;
Box<Order> _orderBox;
Box<InventoryItem> _inventoryBox;
```

**Key Methods**:

| Method | Purpose | Returns |
|--------|---------|---------|
| `initialize()` | Setup Hive & open boxes | Future<void> |
| `addProduct()` | Add new product | Future<void> |
| `getAllProducts()` | Get all products | List<Product> |
| `getProduct(id)` | Get single product | Product? |
| `updateProduct()` | Update product | Future<void> |
| `deleteProduct(id)` | Delete product | Future<void> |
| `getProductsByCategory()` | Filter by category | List<Product> |
| `addOrder()` | Create new order | Future<void> |
| `getAllOrders()` | Get all orders | List<Order> |
| `getOrdersSortedByDate()` | Orders by date | List<Order> |
| `getOrdersByStatus()` | Filter by status | List<Order> |
| `updateOrder()` | Update order | Future<void> |
| `deleteOrder(id)` | Delete order | Future<void> |
| `addInventoryItem()` | Add inventory item | Future<void> |
| `getAllInventoryItems()` | Get all inventory | List<InventoryItem> |
| `getLowStockItems()` | Get low stock items | List<InventoryItem> |
| `updateInventoryItem()` | Update inventory | Future<void> |
| `deleteInventoryItem(id)` | Delete inventory | Future<void> |
| `clearAllData()` | Clear all boxes | Future<void> |
| `getStats()` | Get statistics | Map<String, int> |

## Data Flow

### Creating a Product
```
User Input (MenuScreen)
    ↓
ProductFormScreen validates input
    ↓
DatabaseService.addProduct(product)
    ↓
Hive Box<Product>.put(id, product)
    ↓
Data persisted to disk
    ↓
UI updates with new product
    ↓
Success message displayed
```

### Creating an Order
```
User Input (CreateOrderScreen)
    ↓
User selects products & quantities
    ↓
Order.calculateTotal(items)
    ↓
DatabaseService.addOrder(order)
    ↓
Hive Box<Order>.put(id, order)
    ↓
Data persisted to disk
    ↓
Navigate back to OrderScreen
    ↓
Success message displayed
```

### Updating Inventory
```
User edits item (InventoryFormScreen)
    ↓
Form validation
    ↓
Update lastUpdated timestamp
    ↓
DatabaseService.updateInventoryItem(item)
    ↓
Hive Box<InventoryItem>.put(id, item)
    ↓
Check if isLowStock
    ↓
UI updates with new data
    ↓
Show low stock indicator if needed
```

## State Management

### Approach
- **Pattern**: StatefulWidget with setState()
- **Rationale**: Simple, suitable for small to medium apps
- **Alternative**: Could use Provider, Riverpod, or BLoC for larger apps

### State Updates
```dart
// Loading data
void _loadProducts() {
  setState(() {
    _products = databaseService.getAllProducts();
  });
}

// After CRUD operation
void _addProduct() async {
  await databaseService.addProduct(product);
  _loadProducts(); // Refresh UI
}
```

## Performance Considerations

### Hive Advantages
- Extremely fast read/write operations
- Lazy loading (only loads data when accessed)
- Minimal memory footprint
- No startup time (unlike SQLite)

### UI Optimizations
- ListView.builder for efficient list rendering
- Stateless widgets where possible
- Const constructors for static widgets
- Keys for list items (when needed)

---

## Security Notes

### Data Storage
- Hive stores data in application's private directory
- Not encrypted by default (add hive_crypto for encryption)
- Cleared when app is uninstalled

### Input Safety
- All forms validated before submission
- No SQL injection risk (NoSQL database)
- No user authentication (single-user app)

## Extensibility

### Adding New Features

**New Model:**
1. Create model in `lib/models/new_model.dart`
2. Add Hive annotations
3. Run build_runner
4. Add methods to DatabaseService
5. Create screen in `lib/screens/`

**New Screen:**
1. Create file in `lib/screens/`
2. Add StatefulWidget
3. Accept DatabaseService in constructor
4. Add navigation from existing screen

**New Widget:**
1. Create file in `lib/widgets/`
2. Create StatelessWidget or StatefulWidget
3. Import and use in screens

## Troubleshooting Common Issues

### Build Errors
- Run `flutter clean` then `flutter pub get`
- Regenerate code: `flutter pub run build_runner build --delete-conflicting-outputs`
- Check Flutter version: `flutter doctor`

### UI Issues
- Use Hot Restart (R) instead of Hot Reload (r)
- Check for BuildContext errors
- Verify StatefulWidget setState() calls

### Data Issues
- Confirm Hive initialized: `await databaseService.initialize()`
- Check TypeAdapter registration
- Verify box names are consistent
